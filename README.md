# NB_Batocera2PVE

> 无显卡、无声卡的 Batocera 小盒子的「一键串流 + 集中管理」神器。
> 装上它，就能在 Windows 电脑上像玩主机一样，把 Batocera 里的游戏画面和声音
> 串流到大屏幕上，还能把所有虚拟机盒子集中管起来。

---

## 🎯 它是干什么的？

如果你有几台 **PVE 里的 Batocera 虚拟机**（大多是只有 CPU、没显卡、没声卡的"瘦盒子"），
每台要配 Sunshine 串流、配声卡、配测试面板…… 手动搞能折腾一整天。

**NB_Batocera2PVE** 就是把这些全自动化了：

- **一键部署串流**：自动在盒子装上 Sunshine + 私有音频链路，配好 Web 鉴权，
  无显卡自动软解、无声卡自动造虚拟声卡，盒子开机即续命，重启不丢。
- **集中管理**：所有盒子在一个窗口里列出，IP / 系统版本自动探测，双击 VNC 直连，
  右键就能关机、开机、自愈、改硬件。
- **Batocera 远程控制台**：不用进盒子，在电脑上就能调音量、改分辨率、套手柄/键盘预设、
  备份存档、修游戏、插件市场、系统升级回滚，全都在一个窗口点按钮完成。
- **离线可用**：部署要用的 Sunshine 引擎、音频库等全部打包在发布包里，目标盒子**不用联网**。

### 适合谁用？

- 用 PVE 开 Batocera 虚拟机玩街机 / 复古游戏的玩家；
- 有一堆盒子要统一维护、懒得每台 SSH 的人。

## 🖥️ 界面长这样 —— 主要功能一览

主界面（`pve.py`）打开后，左边填 PVE 宿主机 + Root 密码，点 **⚡ 建立连接**，
右侧就列出所有虚拟机的 **IP / 系统版本 / 运行状态**。

| 按钮 | 干什么 |
|---|---|
| 🎮 直连Batocera串流 | 一键拉起 Moonlight 串流，直接进盒子玩游戏 |
| 🕹️ 虚拟机管理中心 | 主战场：列表 + 右键菜单（开机/关机/自愈/硬件编辑/VNC） |
| 🚀 镜像与存储部署 | 把系统镜像、闲置磁盘挂到虚拟机 |
| 📜 终端控制台与实时日志 | PVE 交互式命令行，直接敲命令 |

### 🕹️ 虚拟机右键菜单

对列表里的任意虚拟机右键：

- **开机 / 关机 / 重启**
- **🔧 自愈**：自动检测典型问题并修复（黑屏、连不上、显卡配置等）
- **🎨 全量硬件编辑**：CPU、内存、磁盘、网卡、VGA、BIOS、直通硬件……图形化改
- **🎮 直连串流**、**📺 VNC 直连**（双击列表行也可呼出 VNC）
- **💻 打开 Batocera 控制台**（详情见下）

## 🎮 Batocera 远程控制台（重点功能）

在 VM 列表对目标盒子打开控制台，**root/linux 自动登录、免密钥免输密码**，
一切操作都走按钮，就像在本地操作一样。控制台分 5 个标签页：

### ⚡ 常用控制
- **连接**：输入盒子 IP → 一键定位 / 连接（SSH + Samba 自动就绪）
- **🔋 电源与维护**：关机、重启、对时（校系统时钟）
- **🩺 屏幕与测试**：随时呼出 / 收起盒子屏幕上的「测试面板」
- 底部 **交互式命令执行**：不想找按钮就自己敲命令，实时回显

### 📦 插件中心
- 🛒 **安装插件中心**：一键装好 Batocera 插件管理器
- 🖥️ **呼出插件中心**：插件的 GUI 直接显示在盒子的屏幕上（通过串流看得见）
- 🇨🇳 **一键汉化市场**：把插件市场界面汉化
- 🔄 **刷新列表 / 刷新 ES 菜单**：装完插件立刻生效
- ✖ **强制退出/解卡**：某个插件卡死时强制踢出去

### 🎮 游戏与系统调优
- **🌍 本地化与网络服务**：改系统语言、时区；开关 Samba 共享 / SSH / Web 控制台 / Syncthing
- **📺 画质与游玩黑科技**：调画面比例、复古滤镜
- **🎮 手柄与键盘键位习惯预设**：
  - 一套「动作冒险」等现成预设一键套用；
  - **✏️ 自定义键位**：点动作右侧按钮 → 在键盘上按一下想要的键 → 自动填入，可存成预设；
  - ⚡ 修复标准热键（Hotkey+Start 退出这类官方默认组合失效时一键修回）
- **💾 保存调优并刷新 ES**：改完全部一键生效

### 💾 存档备份与排障
- **🖥️ 分辨率与音频**：直接改盒子分辨率；选声卡、调音量、🔔 按一下试音
- **💾 游戏存档管理**：一键「打包导出存档到电脑」备份，或「恢复本地存档到盒子」还原
- **🩺 模拟器排障与自愈**：
  - 🩺 诊断游戏报错（自动抓取报错原因）
  - 🚑 一键修复游戏闪退
  - 🔍 扫描缺失 BIOS（并提示放哪个目录）
- 可勾选自愈项，**🚀 立即执行修复**，全部自动完成

### 📋 系统详情
- **🖥️ 系统属性**：盒子系统版本 / 存储空间一眼看全，🔄 随时刷新
- **⬆️ 系统升级与回滚**（安全向导）：
  - 升级前自动做**全量快照备份**（存在 `/userdata/system/backup/`）
  - 🚀 一键执行「备份 → 下载官方升级包 → 部署新系统」，重启后生效
  - 出任何问题，⏪ **一键无损回滚**回升级前状态

> 持久化说明：盒子上只有 `/userdata` 和 `/boot` 重启后保留。控制台里所有
> 对系统的改动都会自动写入持久区，**重启不丢**。

## 🚀 快速开始

### 从源码运行（Windows，需 Python 3.8+）

```bat
pip install -r requirements.txt
python pve.py
```

首次运行：填 **PVE 宿主机 IP + Root 密码** → 连接 → 列表里选中目标盒子 →
右键一键部署。部署过程全自动，完成后盒子上就有串流了。

### 用现成 exe（推荐给玩家）

到 **Release 页面**下载对应版本：

- `NB_Batocera2PVE-版本号-full.exe`：**含缓存版** —— 把 Sunshine 引擎和音频库都
  打进 exe，盒子**不用联网**也能部署（推荐，体积较大）；
- `NB_Batocera2PVE-版本号-lite.exe`：**精简版** —— 体积小，部署时联网自动下载引擎。

双击即用，把它和 VNC 客户端放一起即可（VNC 见下方说明）。

## 🛠️ 打包与发布

### 本地构建 exe

```bat
python build.py            # GUI：勾选「含缓存版 / 精简版」再构建
python build.py --cli full # 无界面：直接出含缓存版
python build.py --cli lite # 无界面：直接出精简版
```

产物在 `dist/`。
> 放到 exe 同目录的 `vncviewer.exe` 会被一起打进去；不放也不影响其余功能。

### GitHub Actions 自动发布

提交到 `main`（或手动触发）会自动：

1. **自动累积版本号**：v3.0.0 → 下一次 v3.0.1 → v3.0.2 …（取最高 tag 的 patch +1）
2. 编译 `full`（含缓存）与 `lite` 两个 exe
3. 打包完整源码 zip（含全部离线缓存，**单文件远低于 GitHub 2GB 上限**）
4. 创建 GitHub Release 并附带三个产物

从此只需 `git push`，玩家在 Release 页就能下到新版本。

## 🔌 VNC 客户端（发布包不含，会自动处理）

`vncviewer.exe` 是 RealVNC 专有二进制，GPL-3.0 不允许随项目再分发，
所以发布包里**没有内置**。程序按顺序自动查找：

内置/已下载 → 本机已装的 VNC（RealVNC / TigerVNC / TightVNC / UltraVNC）→
**从 RealVNC 官方源自动下载解包**到本地目录 → 都没有就用浏览器手动连接提示。

也可以自己放一个：从 RealVNC 官网下载 Viewer 安装后，程序会从注册表自动找到；
或直接把 `vncviewer.exe` 复制到源码的 `modules\` 或 exe 同目录。
